# Curriculum Officiel - Parcours Développement Web & Mobile
### Club Informatique - Programme Annuel de Formation (20 semaines)

---

## 0. Présentation

Dans le cadre des activités du club informatique, ce parcours **Développement Web et Mobile** vise à accompagner progressivement les membres depuis la découverte des technologies du Web jusqu'à la réalisation d'un projet complet intégrant frontend, mobile et backend.

Le programme a été conçu selon une approche fortement pratique, fondée sur l'apprentissage par projet (*project-based learning*), le travail collaboratif et la mise en situation réelle. Chaque notion théorique est immédiatement appliquée à travers des exercices, mini-projets ou contributions au projet fil rouge du parcours.

À l'issue de la formation, les participants disposeront de compétences techniques leur permettant de :
- concevoir des sites web modernes et responsives ;
- collaborer efficacement avec Git et GitHub ;
- développer des interfaces utilisateurs avec React ou Vue ;
- consommer et créer des API ;
- participer au développement d'applications mobiles ;
- travailler en équipe sur un projet informatique ;
- construire un portfolio technique valorisable dans un contexte académique ou professionnel.

Le parcours est organisé sur 20 semaines, réparties en **trois grandes phases pédagogiques** :
1. Fondations Web ;
2. Frontend moderne et gestion de projet ;
3. Développement mobile, backend et restitution finale.

---

## 1. Objectifs

### Public visé

Cette formation s'adresse principalement :
- aux étudiants débutants souhaitant apprendre le développement web ;
- aux membres du club ayant peu ou pas d'expérience en programmation ;
- aux étudiants souhaitant acquérir des compétences pratiques pour des projets personnels, universitaires ou professionnels ;
- aux membres intéressés par les métiers du développement logiciel.

Aucun prérequis technique n'est exigé.
Une maîtrise basique de l'utilisation d'un ordinateur et de la navigation internet est suffisante pour débuter.

### Objectifs pédagogiques

À la fin du parcours, l'apprenant sera capable de :

**Développement Web**
- Structurer une page avec HTML.
- Mettre en forme une interface avec CSS.
- Créer des interfaces responsives adaptées aux différents écrans.
- Manipuler le DOM grâce à JavaScript.
- Déboguer des applications web simples.

**Collaboration et gestion de code**
- Utiliser Git et GitHub.
- Travailler avec des branches.
- Réaliser des Pull Requests.
- Participer à une revue de code.

**Frontend moderne**
- Comprendre l'architecture d'une application React ou Vue.
- Créer des composants réutilisables.
- Gérer l'état d'une application.
- Consommer des API externes.

**Développement Mobile**
- Créer une application mobile simple avec React Native ou Flutter.
- Naviguer entre plusieurs écrans.
- Consommer une API depuis une application mobile.

**Backend**
- Concevoir une API simple.
- Manipuler des bases de données.
- Réaliser des opérations CRUD.
- Déployer un backend.

**Compétences transversales**
- Travailler en équipe.
- Organiser un projet logiciel.
- Présenter un projet technique.
- Construire un portfolio GitHub.

### Charge de travail

La charge de travail est volontairement modérée afin de rester compatible avec les contraintes académiques des membres.

**Temps hebdomadaire estimé :** 3 à 4 heures par semaine.

Répartition moyenne :

| Activité | Durée |
| :--- | :--- |
| Séance encadrée | 2h30 à 3h |
| Travail individuel | 30 min à 1h |
| Travail projet (à partir de la phase 2) | 30 min à 1h |

Les devoirs visent principalement la consolidation des notions vues en séance.

## 2. Séances et rythme

### Fréquence
- Une séance hebdomadaire.
- Majoritairement en présentiel.
- Quelques séances en ligne pour les revues de projet et le suivi.

### Déroulé type d'une séance

**1. Accueil et révision (15 min)**
- Retour sur les exercices précédents.
- Réponses aux difficultés rencontrées.
- Vérification des livrables.

**2. Apport théorique (30 à 45 min)**
Présentation des nouveaux concepts :
- démonstration ;
- exemples ;
- bonnes pratiques ;
- questions-réponses.

**3. Atelier pratique guidé (60 à 90 min)**
Mise en application immédiate :
- exercices individuels ;
- programmation accompagnée ;
- challenges de groupe.

**4. Synthèse et objectifs (15 min)**
- récapitulatif ;
- conseils de progression ;
- présentation du travail à réaliser avant la séance suivante.

### Outils utilisés

**Développement**
- VS Code
- Chrome DevTools

**Gestion de version**
- Git
- GitHub

**Frontend**
- HTML5
- CSS3
- JavaScript ES6+
- React ou Vue

**Mobile**
- React Native ou Flutter

**Backend**
- Node.js
- Express.js
- Firebase (alternative possible)

**Collaboration**
- GitHub Projects
- Discord / WhatsApp / Telegram (selon l'organisation du club)
- Google Meet ou Microsoft Teams pour les séances en ligne

### Encadrement
L'encadrement repose sur :
- les responsables pédagogiques du club ;
- les formateurs principaux ;
- d'éventuels mentors ou anciens membres ;
- les responsables d'équipes projet.

Une attention particulière sera portée à l'accompagnement des débutants.

## 8. Autres dispositions

### Évaluation
L'évaluation sera continue et basée sur :
- la présence et la participation ;
- les livrables hebdomadaires ;
- les devoirs intermédiaires ;
- les contributions GitHub ;
- l'implication dans le projet de groupe ;
- la soutenance finale.

### Conditions de validation
Pour être considéré comme ayant terminé le parcours, le participant devra :
- assister régulièrement aux séances ;
- rendre les principaux livrables ;
- contribuer au projet fil rouge ;
- participer au Demo Day.

### Valorisation des participants
À l'issue du programme, les membres disposeront :
- d'un compte GitHub enrichi ;
- d'un ou plusieurs projets démontrables ;
- d'un portfolio technique en construction ;
- d'une expérience de travail collaboratif ;
- d'une première expérience de présentation technique devant un public.

---

## Conclusion

Ce curriculum a pour ambition de fournir aux membres du club une **première expérience concrète du développement logiciel moderne**, en combinant apprentissage progressif, collaboration, réalisation de projet et ouverture vers le monde professionnel. 

Le projet fil rouge constitue le fil conducteur du parcours et permet de transformer les connaissances acquises en une réalisation tangible, utile et valorisable pour les études, les stages et les futures opportunités professionnelles.
