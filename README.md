## 🎯 Objectifs du semestre

À la fin des 20 semaines, chaque membre doit être capable de :

1. Utiliser Git et GitHub en autonomie (branches, PR, revue de code).
2. Construire une interface web responsive et accessible (HTML/CSS).
3. Développer une application frontend avec React ou Vue.
4. Développer une application mobile avec React Native ou Flutter.
5. Créer une API backend et la connecter à un frontend/mobile.
6. Déployer une application complète en ligne.
7. Présenter un projet technique (démo + pitch).

**Livrable final** : un projet fil rouge déployé, présenté en S20, et un début de portfolio GitHub.

---

## 🧭 Règles de la section

- **Assiduité** : une séance par semaine, présence attendue.
- **Livrables** : chaque séance a un livrable ; les devoirs sont asynchrones.
- **Revue de code** : chaque PR reçoit au moins une relecture (pair ou mentor).
- **Entraide** : les membres avancés aident les débutants pendant les ateliers.
- **Dépôt propre** : chaque projet a un `README.md` avec installation et description.
