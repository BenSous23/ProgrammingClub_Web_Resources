## 2. Sites web playground (navigateur)

Ces outils fonctionnent directement dans le navigateur de votre téléphone ou tablette. Aucune installation n'est nécessaire.

### WebDen

- **Lien :** https://webden.dev/
- **Points forts :**
  - Conçu spécifiquement pour être **optimisé pour les mobiles et tablettes**[reference:8].
  - Éditeurs **HTML, CSS et JS** avec un panneau d'aperçu et une console JavaScript[reference:9].
  - **Application web progressive (PWA)** : peut être installée sur l'écran d'accueil et fonctionner **hors ligne**[reference:10].

### JSitor

- **Lien :** https://jsitor.com/pen
- **Points forts :**
  - Éditeur avancé pour **JavaScript, CSS et HTML** avec **aperçu en temps réel**[reference:11].
  - Supporte plusieurs langages : **JS, JSX, TypeScript, CSS, SASS, SCSS, HTML, Pug**, etc.[reference:12].
  - Idéal pour tester des extraits de code et les partager[reference:13].

## 3. Recommandation pour le club

Pour les séances S1 à S10 (HTML, CSS, JavaScript et introduction à React), **deux options suffisent** :

1. **Sur Android** : installez **HTML Creator** depuis le Play Store. C'est l'outil principal pour écrire et prévisualiser votre code.
2. **Sur iOS ou pour une solution universelle** : utilisez **WebDen** dans le navigateur (Safari ou Chrome). Vous pouvez l'ajouter à votre écran d'accueil pour un accès rapide, comme une application.

**JSitor** peut servir d'outil complémentaire pour tester des extraits de JavaScript plus complexes ou pour partager du code avec le groupe.
